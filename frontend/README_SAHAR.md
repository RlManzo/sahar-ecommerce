# Sahar Frontend - primera adaptación visual

Esta versión parte del frontend del ecommerce base y aplica una primera transformación a Sahar.

## Configuración local
- Frontend: http://localhost:4500
- Proxy API: http://localhost:9393
- Proxy uploads: http://localhost:9393

## Cambios incluidos
- Identidad visual negro + dorado + crema.
- Header/navbar orientado a perfumería y decants.
- Home hero de Sahar.
- Categorías: Perfumes, Decants & frascos, Cuidado personal, Accesorios, Embalaje.
- Catálogo con estilos oscuros y filtros adaptados.
- Marcas de perfumería iniciales en filtro.
- Detalle de producto adaptado a estética premium.
- Carrito lateral oscuro.
- Footer Sahar.
- Puerto Angular por defecto 4500.
- Proxy local a backend 9393.
- Catálogos básicos del administrador actualizados a Sahar.

## Pendiente para la segunda etapa
- Datos reales de contacto, WhatsApp y redes de Sahar.
- Logo final/asset de marca.
- Carga/importación del Excel de catálogo.
- Modelo de precios por volumen para productos mayoristas.
- Campos específicos de perfumes: capacidad, género, familia olfativa y variantes.
- Revisión visual final cuando haya imágenes reales de producto.

## Levantar local
```powershell
npm install
npm start
```

Angular queda configurado para http://localhost:4500.
